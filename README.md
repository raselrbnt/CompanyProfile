## 🚀 Quick Start

```bash
# Clone repository
git clone https://github.com/raselrbnt/CompanyProfile.git
cd CompanyProfile

# Install dependencies
composer install
npm install

# Setup environment
cp .env.example .env
php artisan key:generate

# Setup database
php artisan migrate --seed

# Run development server
php artisan serve
npm run dev
```

**Default Admin Login:**
- URL: http://127.0.0.1:8000/login
- Email: `admin@example.com`
- Password: `password`
